@qmd 를 사용해서 현재 열린 literature 노트에서 permanent 노트를 추출해줘.

## 작업 순서

1. literature 노트의 내용을 분석하여 독립적인 아이디어 단위로 분리
2. 각 아이디어에 대해 qmd deep_search로 기존 permanent 노트와 중복 확인
3. 중복되지 않는 새로운 아이디어를 permanent 노트로 작성

## permanent 노트 작성 규칙

- **하나의 노트 = 하나의 아이디어** (원자적)
- 원문을 그대로 옮기지 말고 **내 언어로 재서술**
- 출처에 원본 literature 노트를 위키링크로 연결
- 5-templates/permanent.md 의 frontmatter 형식을 따를 것
- 파일명: 아이디어를 요약하는 짧은 한글 제목
- 저장 위치: 2-permanent/

## 출력 형식

추출할 아이디어를 먼저 목록으로 보여주고, 승인 후 노트를 생성해줘.

### 추출 가능한 아이디어
1. **제목** — 한 줄 요약
2. ...

각각에 대해 기존 노트와의 관계도 표시.
