Use @qmd to extract permanent notes from the currently open literature note.

## Steps

1. Analyze the literature note's content and separate it into independent idea units
2. Use qmd deep_search to check for duplicates against existing permanent notes
3. Write new permanent notes for non-duplicate ideas

## Permanent Note Writing Rules

- **One note = one idea** (atomic)
- Do NOT copy the original text verbatim — **restate in your own words**
- Link the source literature note via wikilink in the references section
- Follow the frontmatter format from 5-templates/permanent.md
- Filename: Short title summarizing the idea
- Location: 2-permanent/

## Output Format

List the ideas to extract first, then create notes after approval.

### Extractable Ideas
1. **Title** — One-line summary
2. ...

Show the relationship to existing notes for each idea.
